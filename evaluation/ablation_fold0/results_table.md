Source: `metrics.csv` in each config's subfolder here (`baseline/`, `bottleneck/`, `gtcrop/`),
generated by `isles/scripts/evaluate.py`. Computed directly from those files by the snippet
below — not retyped by hand.

```python
import csv
import numpy as np

configs = [
    ("nnU-Net Baseline", "baseline/metrics.csv"),
    ("MetaBottleneck", "bottleneck/metrics.csv"),
    ("GT-Crop + Meta", "gtcrop/metrics.csv"),
]
metrics = [("DSC_1", "DSC"), ("NSD_1", "NSD@1mm"), ("HD95_1", "HD95 (mm)"), ("ASSD_1", "ASSD (mm)")]

for label, path in configs:
    rows = list(csv.DictReader(open(path)))
    cells = [label]
    for col, _ in metrics:
        vals = [float(r[col]) for r in rows if r[col] not in ("", "None")]
        cells.append(f"{np.mean(vals):.3f} ± {np.std(vals):.3f} (n={len(vals)})")
    print(cells)
```
